# MCP configuration maintenance

These files are optional connection presets, not permission to use a service.
Keep credentials out of tracked files. Preserve disabled defaults and the
read-only resource flags. Confirm commands and endpoints against official sources
when changing a preset. Do not bypass host restrictions or silently expand cloud
roles, namespaces, tool allowlists, or approval settings.

Documentation queries contain public library/service names and generic technical
questions only. Do not send private briefs, code, data, logs, identifiers, or
conversation history to documentation servers. Read-only resource calls can still
return secrets or incur charges: use the authorized account and minimum scope,
and do not retrieve secret contents merely because a tool is available.

No server is started by the installation or validation scripts. Distinguish
syntax checks, documented configuration, and an actual authenticated connection.
