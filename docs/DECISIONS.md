# 설계 결정과 근거

현재 대화에서 확정한 요구와, 그 범위 안에서 실제로 선택한 구현만 기록합니다.
사용자 결정과 구현 담당 AI의 선택을 구분합니다. 미선택 제안이나 대화 전문은 포함하지 않습니다.

| ID | 결정 | 대화에서 확인된 이유 | 결정 주체 | 반영 위치 |
| --- | --- | --- | --- | --- |
| D001 | 업무 도메인에 종속되지 않는 공개용 하네스 | 여러 작업에 재사용할 지침·스킬을 미리 준비하려는 요구 | 사용자 | `AGENTS.md`, `.agents/skills/` |
| D002 | 에이전트 지침·스킬은 영어, 사용 설명은 한글 허용 | 스킬 위주로 영어를 사용하고 설명은 한글이어도 된다는 언어 지정 | 사용자 | 모든 `SKILL.md`, `AGENTS.md`, `docs/` |
| D003 | 모던한 UI, 편리한 UX, 일관된 톤앤매너를 명시 | 시각적 완성도와 사용 편의성이 모두 중요하다는 요구 | 사용자 | `harness-frontend`, `docs/UI_DIRECTION.md` |
| D004 | Base UI와 자체 토큰을 기본 제안으로, HeroUI v3와 문서 MCP를 선택지로 제공 | 더 현대적인 대안을 요청했고, 맞춤 스타일과 빠른 기본 구성의 선택 기준을 제공하기로 함 | 구현 담당 AI | `harness-frontend`, `mcp/codex.toml` |
| D005 | API 보안·계약·호환성·확장 경계와 의미 있는 테스트를 명시 | 백엔드 보안, API 설계, 확장성, 테스트 코드가 중요하다는 요구 | 사용자 | `harness-backend`, `harness-test` |
| D006 | 공개 API·OSS·enterprise 기능을 조사하는 아이디어 스킬 제공 | 주제가 주어질 때 외부 기능을 탐색해 아이디어를 설계하려는 요구 | 사용자 | `harness-ideate` |
| D007 | 구현 설명과 결정 근거 추출을 다른 스킬로 분리 | 설계를 설명하는 기능과 AI 대화에서 결정된 설계 이유만 정리하는 기능을 각각 요청 | 사용자 | `harness-explain`, `harness-design-rationale` |
| D008 | 기본 단일 에이전트, 선택적 위임, 짧은 체크포인트 | 문맥 복제·조율·통합이 총 토큰을 늘릴 수 있어 독립 작업에만 위임하는 방식 선택 | 구현 담당 AI | `harness-context`, `docs/TOKEN_AND_AGENTS.md` |
| D009 | 최상위 모델에 의존하지 않고 단계별 완료 기준 사용 | 제한된 모델 조건의 운영 전략을 요청했고, 고정 시간표 제거를 명시 | 사용자 | `docs/MODEL_STRATEGY.md`, `AGENTS.md` |
| D010 | AWS·Azure와 문서 MCP 설정 제공 | 클라우드 MCP까지 준비해 달라는 요청 | 사용자 | `mcp/codex.toml`, `docs/MCP.md` |
| D011 | MCP 비활성 기본값, 리소스 조회는 읽기 제한, 자격 증명 제외 | 대상 환경·계정·허용 범위가 달라 필요한 연결만 선택하도록 구현 | 구현 담당 AI | `mcp/codex.toml`, `mcp/AGENTS.md` |
| D012 | MCP 패키지 버전 고정, Azure는 안정 버전 사용 | 확인한 Azure `latest` 태그가 베타라 안정 버전과 재현 가능한 선택자를 사용 | 구현 담당 AI | `mcp/codex.toml`, `docs/MCP.md` |
| D013 | 기존 프로젝트 파일을 보존하고 설치 충돌 시 적용 전 중단 | 다른 프로젝트에 가져갈 하네스가 기존 지침과 작업을 덮어쓰지 않도록 선택 | 구현 담당 AI | `scripts/install_harness.py`, `tests/test_harness.py` |
| D014 | 사용자 Git 작성자만 사용하고 AI 공동 작성자 표기 제외 | 사용자 작성자만 사용해 커밋·푸시하라는 명시 요청 | 사용자 | `AGENTS.md`, 저장소 로컬 Git 설정 |

D004의 라이브러리 선택은 하네스의 기본 제안이며 특정 제품의 브랜드나 테마가 확정됐다는
뜻은 아닙니다. D011의 읽기 제한은 IAM/RBAC를 대체하지 않습니다. 실제 AI 사용·테스트
기록은 사실대로 남기며, Git 작성자 표기는 인간 단독 작업이라는 주장이 아닙니다.
